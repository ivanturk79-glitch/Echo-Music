# Эхо — стартовый проект Android / iOS

В `www/index.html` помещён присланный HTML-плеер без изменения интерфейса.
`server-reference.py` сохранён отдельно как справочный файл.

## Важно
Это стартовая оболочка Capacitor, а не готовый музыкальный релиз. Исходная страница обращается к `/search` и `/stream/...`, которые обслуживает Flask. Сервер использует путь Termux `/sdcard/музыка`; внутри мобильного приложения он автоматически не заработает. Следующим этапом нужно перенести поиск и воспроизведение на нативный доступ к музыкальной библиотеке Android/iOS и проверить разрешения.

iOS IPA в workflow собирается неподписанным. Для установки на iPhone его потребуется подписать через sideloading-инструмент на Windows. Не помещайте пароли и сертификаты в публичный репозиторий.

## Загрузка в GitHub
1. Создайте публичный репозиторий, например `Echo-Music`.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте **Actions** → **Build Echo apps** → **Run workflow**.
4. После завершения скачайте артефакт `echo-android-debug` или `echo-ios-unsigned-ipa`.

Для локальной Android-подготовки нужен Node.js 22:
```bash
npm install
npx cap add android
npx cap sync android
```
Для сборки iOS нужен macOS с Xcode либо облачный macOS runner из GitHub Actions.
